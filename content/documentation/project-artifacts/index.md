# Project Artifacts

Organize artifacts by discipline and relate them through traceability; do not force a universal hierarchy.

## Routes by Need

| Need | Start Here |
| --- | --- |
| Choose a layer or template | [Disciplinary Layers](./layers/) |
| Define folders and grouping | [Organization](./organization) |
| Assign IDs and relationships | [Identifiers and Traceability](./identifiers-and-traceability) |

The layers cover Strategy, Analysis, Architecture, Delivery and Validation. An artifact should exist because it helps a decision or communication, not to complete a collection.

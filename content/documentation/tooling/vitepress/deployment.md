# VitePress Deployment

Run `npm run docs:build` and publish only the output generated by VitePress. Configure `base` when the site lives under a subpath and test assets, direct routes and the 404 page on the chosen hosting.

Route-compatibility strategy depends on the host. Keep Markdown bridges while there is no equivalent and verified HTTP redirect.

# Spec Document Reference

| File | Purpose | Minimum Content |
| --- | --- | --- |
| `01.requirements.md` | Agree what problem is being solved. | Objective, need, scope, dependencies and criteria. |
| `02.analysis.md` | Understand options and constraints. | State, findings, alternatives, approach and risks. |
| `03.plan.md` | Order the execution. | Strategy, phases and validations. |
| `03.plan.rev-NN.md` | Adjust the plan without erasing history. | Reason, changes, pending items and conclusion. |
| `04.exec.phase-NN.md` | Record an executed phase. | Objective, changes, evidence and artifacts. |
| `05.summary.md` | Close the spec. | Solution, phases, adjustments, validation and pending items. |

Use stable names and two-digit consecutives. See the [broad reference](./specs-driven-development-reference) for complete templates.

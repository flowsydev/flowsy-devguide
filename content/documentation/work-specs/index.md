# Work Specs

Use a spec when the change needs to preserve decisions, dependencies, approval or evidence across several phases. For small and direct changes, a task or PBI may be enough.

## Path

1. [Workflow](./workflow): sequence and approval points.
2. [Document Reference](./document-reference): purpose of each file.
3. [Context Guide for Agents](/ai-assisted-development/context-guides/specs-driven-development): minimum execution context.

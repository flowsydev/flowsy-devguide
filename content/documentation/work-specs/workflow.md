# Specs Workflow

1. Document requirements and acceptance criteria.
2. Analyze current state, alternatives, constraints and risks.
3. Propose a phased plan with validations.
4. Obtain the required approval before executing sensitive phases.
5. Record each executed phase with changes and evidence.
6. Close with a summary that compares the result against the original objective.

Do not treat plan approval as implicit authorization for external actions such as publishing, deploying or modifying systems outside the scope. Later reviews are added as new documents to preserve history.

# Database Migrations

1. Read [Migration Concepts](./concepts).
2. Compare [Tools and Strategies](./tools-and-strategies).
3. When applicable, use the [flwdb CLI](./flwdb-cli).
4. Define evidence with [Migration Testing](/quality/systems/database-migrations).

Versioned scripts describe one-time changes; repeatable scripts recreate objects whose full content is the desired state. Adapt paths to the stack and keep domain language consistent.

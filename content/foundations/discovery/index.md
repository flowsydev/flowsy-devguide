# Domain Discovery

Start with [Design Techniques](./design-techniques) to choose a practice. Use [Event Storming](./event-storming) when you need to visualize business flow, uncertainties, actors and events. Capture the resulting vocabulary in [Ubiquitous Language](../ubiquitous-language).

Discovery produces knowledge and options; it does not by itself impose a code architecture.

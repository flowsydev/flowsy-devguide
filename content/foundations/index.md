1. Define the [Ubiquitous Language](./ubiquitous-language).
2. Run collaborative discovery with [Event Storming](/foundations/discovery/event-storming).
3. Delimit [Bounded Contexts](./domain-modeling/bounded-contexts).
4. Apply tactical patterns only where behavior justifies them.

# Conventions

Coding, naming and source control guidelines for projects in the Flowsy ecosystem. Defines style rules, naming and consistent patterns across the entire technology stack.

## Available Guides

- [C#](./csharp) — Naming, patterns and best practices for backend projects in C#.
- [TypeScript](./typescript) — Standard for frontend projects with Vue 3 + Composition API + strict TypeScript.
- [Vue](./vue) — Development guidelines for components, composables and Vue 3 application structure.
- [PostgreSQL](./postgresql) — Naming and modeling for PostgreSQL databases.
- [SQL Server](./sql-server) — Naming and modeling for SQL Server and Azure SQL databases.
- [MySQL and MariaDB](./mysql-mariadb) — Naming and modeling for MySQL and MariaDB databases.
- [Git](./source-control/git) — GitFlow-based branch strategy, commit convention and semantic versioning.
- [Repository Documentation](./repository-documentation) — README, agent instructions, specs and local documentation conventions.

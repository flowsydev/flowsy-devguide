# Specs

This folder contains internal repository specs used to record concrete changes to the guide, including requirements, analysis, work plans and execution evidence.

## Repository Convention

- Specs are grouped by line of work under `specs/`.
- Each spec uses, when applicable, the sequence from `01.requirements.md` to `05.summary.md`.
- `assets/` folders keep research inputs or auxiliary context that should not be published as part of the site.

## Groups

- [Documentation Architecture](./documentation-architecture/README.md): migration from Discovery/Technologies to the intent-based Foundations, Documentation, Engineering, Quality, AI-Assisted Development and Conventions taxonomy. Supporting diagnosis lives under `docs/`.

## Operational Note

`specs/` is excluded from the VitePress build because it is internal work documentation, not navigable site content.

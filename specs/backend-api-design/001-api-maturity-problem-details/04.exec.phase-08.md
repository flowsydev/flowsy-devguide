# Execution Phase 08 - Add Global Exception Handler Guidance

## Phase Scope

Added C# HTTP API guidance for centralizing domain-error mapping through a global exception handler.

## Changes Made

- Updated `technologies/backend/api-design.md` to recommend a global exception handler for C# APIs.
- Updated `technologies/backend/vertical-slice-architecture/csharp-minimal-apis.md` so the endpoint example only handles the success path.
- Added an `IExceptionHandler` example that maps:
  - `EntityNotFoundException` to `404`;
  - `DomainConflictException` to `409`;
  - `DomainValidationException` to `422`;
  - unexpected exceptions to sanitized `500`.
- Added top-level Problem Details `code` values in the centralized handler.
- Kept endpoint metadata documenting known Problem Details responses.
- Updated `CHANGELOG.md`.

# Update Discovery Requirement Templates - Plan

## Strategy

Make focused editorial updates to discovery requirement templates and validate the documentation site.

## Phase 1 - Review Templates

- Inspect requirement, acceptance criteria and related validation templates.
- Identify unclear wording or missing structure.

## Phase 2 - Apply Updates

- Improve headings and prompts.
- Use generic examples.
- Preserve reusable Markdown structure.

## Phase 3 - Validate

- Review links and terminology.
- Run `npm run docs:build`.

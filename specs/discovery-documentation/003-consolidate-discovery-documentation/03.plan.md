# Consolidate Discovery Documentation - Plan

## Strategy

Consolidate discovery documentation in phases, keeping each phase independently reviewable.

## Phase 1 - Section Structure

- Review discovery documentation indexes.
- Clarify the purpose of each artifact group.
- Update navigation where needed.

## Phase 2 - Writing Guidance

- Add or refine writing guidelines.
- Cover tone, terminology, Markdown structure, links and examples.

## Phase 3 - Repository Documentation

- Connect discovery documentation with repository files such as `README.md`, `AGENTS.md`, `CHANGELOG.md` and specs.
- Clarify how specs relate to durable documentation.

## Phase 4 - Cross-References

- Link relevant AI-assisted development context guides.
- Update section indexes.

## Phase 5 - Validation

- Review terminology and links.
- Run `npm run docs:build`.

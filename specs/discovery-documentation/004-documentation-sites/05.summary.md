# Resumen — Reorganización de `discovery/documentation/` y Sección de Sitios de Documentación

## Objetivo Original

Reorganizar `discovery/documentation/` para separar el contenido de capas disciplinarias del contenido sobre herramientas de sitios de documentación, introduciendo un gateway raíz y una nueva sección `static-site-generators/` con una guía de VitePress.

## Solución Ejecutada

La reorganización se completó en seis fases:

1. **Migración** — los archivos existentes en `discovery/documentation/` se movieron a `discovery/documentation/layers/` usando `git mv`, preservando el historial. Todos los links absolutos en los archivos migrados y en cuatro archivos externos que no estaban en el plan original se actualizaron para reflejar las nuevas rutas.
2. **Folder Structure** — el bloque de ejemplo en `layers/index.md` se actualizó para mostrar `layers/` como directorio contenedor de las capas disciplinarias, con todos los elementos ordenados alfabéticamente.
3. **Gateway raíz** — se creó `discovery/documentation/index.md` con `layout: section-home`, presentando `Disciplinary Layers` y `Static Site Generators` como las dos subsecciones del área.
4. **Sección `static-site-generators`** — se creó el directorio y su `index.md` con hero, feature card a VitePress y back link al gateway.
5. **Contenido VitePress** — se creó `vitepress.md` con siete subsecciones: inicio rápido, configuración base, estructura disciplinaria, layouts y componentes, plugins recomendados (incluyendo `vitepress-plugin-mermaid`), despliegue y referencias.
6. **Sidebar estructurado** — `config.ts` se actualizó con el nodo agrupador `Disciplinary Layers`, todas las rutas de capa migradas a `/layers/`, y el nuevo nodo `Static Site Generators` con su hoja `VitePress`.

# Plan Rev. 01 — Reubicar Writing Guidelines Fuera de `layers/`

## Cambios Respecto al Plan Base

### 1. Posición exacta en nav y sidebar

El plan base indicaba "al final de los ítems existentes" para el sidebar y no especificaba posición en el nav. Tras revisar el orden actual de ambas estructuras, la posición correcta es **después de "Repository Documentation"** en el nav y en el sidebar del grupo "Conventions". Ambos documentos son convenciones de escritura no técnicas; agruparlos al inicio del bloque, antes de las guías de lenguaje (C#, TypeScript, Vue…), mejora la jerarquía semántica.

**Nav — grupo "Conventions" resultante:**

```
{ text: 'Overview', link: '/conventions/' },
{ text: 'Repository Documentation', link: '/conventions/repository-documentation' },
{ text: 'Writing Guidelines', link: '/conventions/writing-guidelines' },   ← nueva posición
{ text: 'C#', link: '/technologies/backend/dotnet/csharp' },
...
```

**Sidebar — grupo "Conventions" resultante:**

```
{ text: 'Overview', link: '/conventions/' },
{ text: 'Repository Documentation', link: '/conventions/repository-documentation' },
{ text: 'Writing Guidelines', link: '/conventions/writing-guidelines' },   ← nueva posición
{ text: 'C#', link: '/technologies/backend/dotnet/csharp' },
...
```

### 2. `AGENTS.md` tiene la ruta pre-spec-004

El plan base asumía que `AGENTS.md` referenciaba la ruta `discovery/documentation/layers/writing-guidelines.md`. Sin embargo, el archivo quedó con la ruta anterior al spec 004: `discovery/documentation/writing-guidelines.md`. La Fase 2 debe actualizar esa línea directamente a `conventions/writing-guidelines.md`.

Línea actual en `AGENTS.md:70`:

```
- `discovery/documentation/writing-guidelines.md`: editorial rules for durable documentation.
```

Debe quedar:

```
- `conventions/writing-guidelines.md`: editorial rules for durable documentation.
```

### 3. El link en `layers/index.md` se conserva

El plan base no aclaraba si la referencia en `discovery/documentation/layers/index.md` debía mantenerse o eliminarse. Se mantiene en ambos lugares (frontmatter `actions` y cuerpo), solo se actualiza la ruta. El documento de capas sigue siendo el principal punto de entrada para quien produce artefactos de discovery, y los lineamientos de escritura son contexto relevante ahí.

### 4. Entrada en `conventions/index.md`: solo en `features`, no en `actions`

Las `actions` del frontmatter de `conventions/index.md` son botones de llamada a la acción en el hero. Actualmente apuntan a las tres convenciones de código más usadas (C#, TypeScript, Git). No se agrega Writing Guidelines a los `actions` para no sobrecargarlo; la visibilidad está cubierta por la tarjeta en `features` y la entrada en "Available Guides".

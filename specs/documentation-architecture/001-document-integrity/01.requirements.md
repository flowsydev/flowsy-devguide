# 001 — Document Integrity

## Intent

Fix proven link defects, local duplication and Vue context-guide drift without moving pages or changing public routes.

## Audience

Maintainers of Flowsy DevGuide preparing structural migration.

## Requirements

1. Fix `actions` and `features` links on Strategy, Analysis, Architecture, Delivery and Validation landings that omit `/layers/` toward templates.
2. Remove consecutive duplicate examples in Testing pages and the Vue context guide.
3. Align Vue guidance: `navigation/` → `routing/`; distinguish logical `state` from physical `stores/`; unify UI/API contract decision so one page owns the policy and others summarize and link.
4. Complete section maps that omit already-published sidebar pages.
5. Add a reproducible Markdown and frontmatter link validator exposed as an `npm` command.
6. Do not move files, adopt the target taxonomy yet, split long pages or change documentary IDs.

## Out of Scope

- Physical reorganization into Foundations, Documentation, Engineering or Quality.
- Mermaid `manualChunks` review.
- Edits under `.vitepress/dist/`.

## Acceptance Criteria

- No published internal link resolves to a nonexistent route.
- Vue context guide matches Modular Architecture and Vue Ecosystem.
- Duplicate examples are gone.
- `npm run docs:validate` and `npm run docs:build` succeed.
- No public routes change in this work line.
